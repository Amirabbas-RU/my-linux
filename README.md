# My Linux

An Arch Linux-based distribution built with
Hyprland and Quickshell.

## Project structure

- docs/       Architecture and development documentation
- desktop/    Hyprland and Quickshell configuration
- system/     System scripts and service configuration
- packages/   Package lists for the distribution
- iso/        Archiso build configuration
- installer/  Installation tooling
- tests/      Project tests

## Development

We develop and test changes separately before
merging them into the main branch.
