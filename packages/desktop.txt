# MyLinux desktop package set
#
# Layered on top of packages/base.txt for machines that install the MyLinux
# desktop. Provides the Hyprland Wayland session, the Quickshell shell runtime,
# XDG portals, a display manager and the day-to-day desktop utilities that the
# MyLinux shell (panel, launcher, OSD, lock screen) depends on.
