# MyLinux live ISO package set
#
# Installed into the *live* environment by the Archiso profile at
# iso/airootfs. This is the environment the user boots into to run the
# MyLinux installer. It is intentionally richer than the installed base:
# it must be able to partition disks, mount filesystems, run pacstrap,
# and drive the installer TUI over the network or from local media.
